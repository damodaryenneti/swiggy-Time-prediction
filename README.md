# Swiggy Delivery Time Prediction

Regression project that predicts food delivery time (ETA) from order, rider and location features.

## Contents
- Notebook: data cleaning, EDA, feature engineering, model building
- Dataset: swiggy_demographic.csv

## Tech stack
Python, pandas, NumPy, scikit-learn, Matplotlib, Seaborn

## How to run
pip install -r requirements.txt
jupyter notebook
